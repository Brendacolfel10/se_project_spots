# Project 3: Spots

### Overview  

Spots is a responsive social media webpage where users can view a profile and a collection of photo cards. The project is designed to display correctly across desktop, tablet, and mobile screen sizes. 
  
**Intro**
  
This project is made so all the elements are displayed correctly on popular screen sizes. We recommend investing more time in completing this project, since it's more difficult than previous ones.  

### Features

- Responsive layout
- User profile section
- Edit Profile button
- New Post button
- Photo card gallery
- Like button hover effects
- Text overflow with ellipsis
- Desktop, tablet, and mobile layouts

## Technologies and Techniques Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media queries
- Responsive Web Design
- BEM methodology
- CSS hover states
- Text overflow and ellipsis
- Figma for design specifications
- Git and GitHub
